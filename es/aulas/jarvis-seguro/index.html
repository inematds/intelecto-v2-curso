Clase 1 · 12 min

Por qué tener tu propio Jarvis y cómo mantenerlo seguro

Antes de confiarle tus archivos a la IA, mira qué puede hacer y cuándo te pide tu OK. Un error o un texto malicioso oculto en un sitio puede hacer que la IA borre una carpeta o envíe una contraseña al exterior. Probado en Linux (Ubuntu). macOS: el código no se probó en vivo. Windows: solo mediante WSL (Ubuntu dentro de Windows), no se probó.

La caja del agente es otra capa: protege la copia de un proyecto cuando un agente de programación trabaja en él.

02 · El recorrido de un mensaje

Del terminal o celular hasta la respuesta, en seis etapas de la guía del proyecto.

1. Canal

El mensaje llega por el terminal o Telegram. En Telegram, el bot comprueba si el id pertenece a la lista de dueños; ignora y registra los mensajes de otros remitentes.

2. Memoria directa

Una solicitud que empieza con «recuerda que», «guarda» o «anota» se guarda directamente, sin esperar a que la IA llame a una herramienta. Una pregunta con ? no se convierte en memoria.

3. Contexto

El asistente reúne los archivos de identidad, los recuerdos relacionados con la pregunta y las conversaciones recientes.

4. Cerebro

La IA local o de la nube recibe este contexto. Responde o solicita una herramienta, como buscar en la memoria, leer un archivo o ejecutar un comando.

5. Bloqueo

El comando solicitado pasa por el bloqueo: se ejecuta, pide tu aprobación o se rechaza. Si lo apruebas, se ejecuta en el área de trabajo o en la caja, si está activada; el resultado vuelve a la IA.

6. Respuesta

Recibes la respuesta. Los comandos, las herramientas, las memorias directas y los errores quedan registrados en la auditoría para que puedas revisarlos.

03 · Qué demuestra la demo

Haz clic en cada etapa para ver qué hacer.

1. Prepara el terminal

En Linux (Ubuntu), instala Python 3.10+ y git. En macOS, instala las herramientas de línea de comandos con xcode-select --install; puedes instalar Python 3.10+ desde python.org o con brew install python. En Windows, usa WSL con Ubuntu. Comprueba las versiones antes de continuar. Si python3 --version muestra una versión anterior a 3.10, usa Ubuntu 22.04 o una versión posterior antes de continuar.

2. Descarga y ejecuta la demo

Descarga INTELECTO, entra en la carpeta y ejecuta demo. La demo usa un cerebro simulado y muestra la memoria, la lectura permitida, la escritura rechazada y el comando bloqueado.

3. Memoria

El cerebro simulado guarda «me llamo Ana y vivo en Curitiba» y responde a la siguiente pregunta. Esta prueba es del mecanismo; en la clase 3 harás la prueba con Ollama.

4. Comandos

«ls» se ejecuta. «echo teste > nota.txt» pide aprobación y se rechaza en la demo. «rm -rf /» queda bloqueado.

5. Área

La solicitud para leer ../../etc/passwd recibe «fora da pasta de trabalho» (fuera de la carpeta de trabajo).

04 · Ejecútalo sin instalar un modelo

En macOS, Python 3.10+ también puede venir de python.org; usa brew install python solo si tienes Homebrew. Ejecuta los bloques de tu sistema y luego descarga el proyecto.

Linux (Ubuntu) · requisitos previos
sudo apt install -y git python3 curl
python3 --version && git --version
macOS · instalar herramientas de terminal y git
xcode-select --install
git --version
macOS · Python 3.10+ con Homebrew
brew install python
python3 --version
Terminal · descargar el proyecto y entrar
cd ~ && git clone https://github.com/inematds/intelecto-v2 && cd intelecto-v2
Terminal · ejecutar la demostración
python3 -m intelecto demo
Ejemplo del repositorio
livre     rodou=True  ls
aprovar   rodou=False echo teste > nota.txt
bloqueado rodou=False rm -rf /

El programa muestra esto en portugués, tal cual.
