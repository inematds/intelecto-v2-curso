Clase 9 · 18 min

Arma el tuyo: la tienda de comestibles y meu-assistente.md

INTELECTO v2 ya funciona. La tienda de comestibles te ayuda a elegir qué agregar: crea un archivo .md con los ingredientes, el estado de cada uno en el proyecto y reglas para un agente de programación. Puedes simplemente leer un ejemplo listo, sin usar un agente ni gastar créditos.

Empezar la clase

En esta clase vas a

  1. 1Elegir ingredientes o cargar un ejemplo listo
  2. 2Leer el total, los marcadores y los archivos mencionados en el .md
  3. 3Entregarle un elemento a la vez al agente y revisar las pruebas

Objetivo: Elegir un ejemplo, interpretar los marcadores del .md y decir qué ya existe y qué todavía hay que implementar.

01 · De la elección al plan de trabajo

Haz clic en los tres pasos. Los símbolos indican qué ya existe y qué falta.

Haz clic en cada bloque del diagrama para ver qué hace.

✅ ya existe en INTELECTO v2, con el archivo · 🟡 existe en parte · ➕ hay que agregarlo, con la pieza indicada.

02 · Qué hay en el archivo

La página arma una lista de trabajo; no instala funcionalidades.

1. Cinco puntos de partida

Jarvis personal en Telegram: 12 elementos (✅ 5, 🟡 3, ➕ 4). Asistente de un pequeño negocio: 12 (✅ 2, 🟡 2, ➕ 8). Programador seguro: 12 (✅ 4, 🟡 0, ➕ 8).

2. Dos ejemplos más

100% local y privado: 10 elementos (✅ 5, 🟡 1, ➕ 4). Casa inteligente con voz: 12 (✅ 2, 🟡 0, ➕ 10). Los cinco archivos están en la carpeta ejemplos/ del repositorio.

3. Leyenda

✅ ya existe y cita el archivo real, como intelecto/canales/telegram.py; 🟡 existe en parte y dice qué falta; ➕ todavía no existe e indica la pieza a la que el agente puede añadir código.

4. Reglas al final

El .md indica que se implemente un ingrediente a la vez, se escriba una prueba en tests/ y se ejecute python3 -m pytest -q. También indica que se conserve el bloqueo, se guarden los secretos solo en la bóveda, se hagan pruebas sin una API real, se actualice la tabla del proceso en README cuando cambie el uso y se diga «listo» solo con el resultado de las pruebas.

03 · Abre un ejemplo y entrega el plan

La primera prueba solo lee el archivo y no usa un agente. La segunda es opcional y usa tu suscripción o los créditos del agente.

Terminal · leer el ejemplo sin costo
cd ~/intelecto-v2
less exemplos/01-jarvis-telegram.md
# Presiona q para salir de less.
Terminal · copiar el ejemplo al proyecto
cd ~/intelecto-v2 && cp exemplos/01-jarvis-telegram.md meu-assistente.md
Con Claude Code o Codex abierto en la carpeta
Lee meu-assistente.md e implementa los elementos por añadir y los parciales, uno a la vez, siguiendo las Reglas para el agente.
Terminal · contar las pruebas antes y después de un elemento
sudo apt install -y python3-pytest   # el programa de pruebas (solo una vez)
cd ~/intelecto-v2
python3 -m pytest -q
Práctica opcional · pedido para UN elemento ➕
Lee meu-assistente.md. Elige solo UN elemento marcado ➕, impleméntalo, escribe la prueba en tests/ y ejecuta python3 -m pytest -q. Muestra el código modificado y el resultado de las pruebas.

04 · Quién hace qué

La tienda crea el plan en Markdown. El agente de programación escribe el código de los elementos 🟡 y ➕; tú debes revisar lo que hizo. Esto usa tu suscripción o los créditos del agente. Más seguro: ejecuta el agente en la caja-del-agente y aplica al original solo el parche revisado.

Para un archivo descargado de la tienda, copia ~/Downloads/meu-assistente.md a ~/intelecto-v2/. Si usas el ejemplo del repositorio, el bloque de arriba lo copia sin descargarlo.

05 · Hazlo en dos niveles

La primera práctica no necesita un agente, Docker ni pago.

Lee la lista lista

5

Abre ejemplos/01-jarvis-telegram.md en el repositorio o descarga un ejemplo de la tienda. Busca la línea «Total: …» y un elemento ✅ con la ruta del archivo. En Jarvis, usa el bot de Telegram como ejemplo.

Listo cuando: Puedes decir: 12 elementos; ✅ 5, 🟡 3 y ➕ 4; y mencionar el archivo de un ✅, por ejemplo intelecto/canales/telegram.py.

Opcional: implementa solo un ➕

12

Instala el programa de pruebas una vez (sudo apt install -y python3-pytest). Copia meu-assistente.md a ~/intelecto-v2, ejecuta python3 -m pytest -q y anota cuántas pruebas pasan. Entrega al agente solo UN elemento ➕, siguiendo las reglas del archivo. El agente escribe el código; revisa el parche o los cambios y vuelve a ejecutar las pruebas. Usa tu suscripción o los créditos del agente.

Listo cuando: python3 -m pytest -q pasa después del cambio y muestra más pruebas aprobadas que antes. Revisaste el código que produjo el agente.
