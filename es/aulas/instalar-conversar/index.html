Instalar y conversar en la terminal

Ya descargaste el proyecto en la clase 1. Ahora elige una IA local que funcione en tu computadora, responde las siete preguntas de configurar y revisa la instalación antes de conversar.

02 · Primer uso, en orden

Haz clic en cada etapa para ver qué hacer.

1. Entrar al proyecto

Entra en ~/intelecto-v2. Si todavía no descargaste el proyecto, clónalo como en la clase 1.

2. Instalar el cerebro

En Linux, instala Ollama con el comando oficial de abajo; en macOS, descarga la aplicación en ollama.com. Después usa ollama pull para descargar el modelo elegido.

Prueba en vivo del 13/11/2026: con llama3.2, el asistente guardó directamente “recuerda que mi nombre es Nei y vivo en Porto Alegre” y lo recordó en una conversación nueva. Esto funciona incluso cuando el modelo pequeño no llama a la herramienta de memoria. Sigue usando poco las otras herramientas, como archivos y comandos. qwen3.6:35b-a3b llamó a herramientas en la prueba, pero su archivo local es mucho más grande.

3. Elegir opciones

Las siete respuestas: nombre y personalidad en frases libres; cerebro ollama; modelo, uno de los que muestra configurar; dónde ejecutar comandos, local; aprobación, perigosos; ids de Telegram, vacíos por ahora. Enter conserva el valor entre corchetes. Telegram es un canal de conversación, no el proveedor del modelo.

El ejecutor es el programa que ejecuta el comando; elige local ahora y conoce la caja Docker en la clase 6. OpenRouter es un servicio pago en la nube y no forma parte de esta práctica.

La política de aprobación tiene tres opciones: perigosos (peligrosos; la predeterminada) permite ejecutar la lectura conocida y pregunta antes de las demás acciones; sempre (siempre) pregunta antes de cualquier comando, incluidos ls y cat; nunca permite ejecutar la lectura conocida, pero rechaza lo que pediría aprobación. Los comandos bloqueados por el seguro no se ejecutan con ninguna opción.

4. Revisar y conversar

verificar revisa lo que exige la configuración actual. “todo listo” no demuestra que el modelo vaya a usar herramientas; inicia una conversación real para comprobarlo. SQLite con FTS5 significa memoria local con búsqueda de texto. Fernet es el modo de cifrar la bóveda cuando está instalada la biblioteca cryptography. En Ubuntu, si quieres usar la bóveda con Fernet, instala python3-cryptography con el gestor de paquetes; pip install cryptography puede fallar con externally-managed-environment en Ubuntu 24.04.

04 · Comandos del proyecto

Copia los comandos y ejecútalos en la terminal desde la carpeta indicada.

Terminal · entrar en la carpeta de la lección 1
cd ~/intelecto-v2
Ubuntu · Fernet en la bóveda (opcional)
sudo apt install -y python3-cryptography
Linux · instalar Ollama
curl -fsSL https://ollama.com/install.sh | sh
Terminal · descargar el modelo común
ollama pull llama3.2
Opcional · modelo para tarjeta grande
ollama pull qwen3.6:35b-a3b
Terminal · configurar y comprobar
python3 -m intelecto configurar
python3 -m intelecto verificar
Terminal · conversar
python3 -m intelecto
