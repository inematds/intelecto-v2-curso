Aula 2 · 16 min

Instalar e conversar no terminal

Você já baixou o projeto na aula 1. Agora escolha uma IA local que caiba no seu computador, responda às sete perguntas do configurar e confira a instalação antes de conversar.

Começar a aula

Nesta aula você vai

Objetivo: Configurar o INTELECTO com Ollama local e confirmar que verificar termina em “tudo certo”.

02 · Primeiro uso, em ordem

Clique em cada etapa para ver o que fazer.

1. Entrar no projeto

Entre em ~/intelecto-v2. Se ainda não baixou o projeto, faça o clone da aula 1.

2. Instalar o cérebro

No Linux, instale o Ollama com o comando oficial abaixo; no macOS, baixe o aplicativo em ollama.com. Depois use ollama pull para baixar o modelo escolhido.

Teste ao vivo em 13/11/2026: com llama3.2, “lembre que meu nome é Nei e moro em Porto Alegre” foi guardado diretamente pelo assistente e lembrado numa conversa nova. Isso funciona mesmo quando o modelo pequeno não chama a ferramenta de memória. Ele continua usando pouco as outras ferramentas, como arquivos e comandos. qwen3.6:35b-a3b chamou ferramentas no teste, mas seu arquivo local é muito maior.

3. Escolher opções

As sete respostas: nome e personalidade em frases livres; cérebro ollama; modelo um dos listados pelo configurar; onde rodar comandos local; aprovação perigosos; ids do Telegram vazios por enquanto. Enter mantém o valor entre colchetes. Telegram é um canal de conversa, não o provedor do modelo.

Executor é o programa que roda o comando; escolha local agora e veja a caixa Docker na aula 6. OpenRouter é um serviço pago na nuvem e não faz parte desta prática.

A política de aprovação tem três escolhas: perigosos (padrão) deixa a leitura conhecida rodar e pergunta para as outras ações; sempre pergunta antes de qualquer comando, inclusive ls e cat; nunca deixa a leitura conhecida rodar, mas recusa o que pediria aprovação. Comandos bloqueados pela trava não rodam em nenhuma delas.

4. Conferir e conversar

verificar confere o que a configuração atual exige. “tudo certo” não prova que o modelo usará ferramentas; faça uma conversa real para conferir. SQLite com FTS5 significa memória local com busca de texto. Fernet é o modo de cifrar o cofre quando a biblioteca cryptography está instalada. No Ubuntu, se você quiser o cofre com Fernet, instale python3-cryptography pelo gerenciador de pacotes; pip install cryptography pode falhar com externally-managed-environment no Ubuntu 24.04.

Tamanhos somados dos arquivos indicados pelos registros de modelos instalados nesta máquina em 13/11/2026; o download pode variar. Não são medidas de RAM.

Placa de vídeo grandeqwen3.6:35b-a3b23,94 GB (23.938.333.115 bytes). Chamou ferramentas no teste ao vivo.

Comece pelo modelo que sua máquina consegue baixar e executar. O tamanho do arquivo não garante que ele caiba na memória. O llama3.2 lembra fatos pedidos com “lembre que…”, mesmo em computador comum; para usar outras ferramentas, confira se o modelo realmente as chamou.

04 · Comandos do projeto

Copie os comandos e rode no terminal a partir da pasta indicada.

Terminal · entrar na pasta da aula 1
cd ~/intelecto-v2
Ubuntu · Fernet no cofre (opcional)
sudo apt install -y python3-cryptography
Linux · instalar Ollama
curl -fsSL https://ollama.com/install.sh | sh
Terminal · baixar o modelo comum
ollama pull llama3.2
Opcional · modelo para placa grande
ollama pull qwen3.6:35b-a3b
Terminal · configurar e conferir
python3 -m intelecto configurar
python3 -m intelecto verificar
Terminal · conversar
python3 -m intelecto
