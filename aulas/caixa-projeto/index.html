Aula 7 · 20 min

A caixa-do-agente no seu projeto

Você precisa do Docker instalado na aula 6; só as aulas 6 e 7 pedem Docker. Aqui, a caixa-do-agente trabalha numa cópia do projeto. Faça uma mudança pequena sem chave, leia o patch e decida se aplica. Você também aprende como deixar agentes trabalharem numa cópia, em um exemplo opcional não executado neste curso.

Começar a aula

Nesta aula você vai

  1. 1Entender criar, rodar e destruir
  2. 2Revisar patch e aplicar conscientemente
  3. 3Ler a nota do auditor sem confundi-la com nota do modelo

Objetivo: Criar e ler um patch sem chave, aplicar a mudança revisada no projeto e desfazê-la.

02 · Duas ferramentas no kit

Clique em cada etapa para ver o que fazer.

1. caixa.sh

O fluxo cria → roda → destrói usa uma cópia: .env, chaves .pem e ~/.ssh ficam fora. A imagem Docker é o molde da caixa; sem --aplicar, o original fica intacto. Há teto de memória, CPU e tempo.

Com --rede, a caixa ganha acesso à rede. Com --env ANTHROPIC_API_KEY, só essa chave entra. O comando opcional com agente usa sua chave e pode enviar o conteúdo da cópia ao serviço do agente; não foi executado neste curso. --dangerously-skip-permissions desliga as perguntas internas do agente na cópia. Confira o patch antes de aplicar.

No macOS, a caixa.sh também precisa do comando timeout: instale coreutils com brew install coreutils, conforme o README do kit.

2. Patch

Patch é um arquivo de texto com as mudanças. O .patch fica na pasta de onde você rodou caixa.sh, ou na pasta indicada por --patch PASTA. Leia com less (aperte q para sair) antes de aplicar. Em patch -p1, o -p1 tira o primeiro pedaço do caminho, “antes/” ou “trabalho/”, para casar com o arquivo da sua pasta. Use o nome exato mostrado pela caixa.

Para arquivo novo, a linha antes/ no cabeçalho do patch pode mostrar 1969; ela representa a ausência do arquivo antes da execução.

3. auditar.py

O auditor lê Claude Code, Codex e DeepSeek Harness instalados no computador, além do projeto. Harness é o programa que roda comandos do modelo; sandbox é o limite ao que ele alcança. Sem nenhum desses programas, a nota sai baixa e isso é normal; ela não mede a inteligência da IA.

4. Caso real

A primeira prática usa ~/intelecto-v2 e a imagem pública python:3.12-slim; não pede chave nem agente de nuvem. A segunda roda testes numa imagem preparada com pytest, o programa de testes Python. O README do projeto documenta 67 testes passados e 1 pulado em uma medição anterior; confira sua própria saída.

03 · Crie, leia e aplique um patch sem chave

O Docker da aula 6 já deve funcionar. Comece na pasta pessoal e use o caminho completo da caixa.sh; o patch fica em ~. Substitua AAAAMMDD-HHMMSS pelo nome que a caixa imprimir.

Terminal · baixar o kit uma vez
cd ~ && git clone https://github.com/inematds/caixa-do-agente
macOS · requisito do caixa.sh
brew install coreutils
Ubuntu · conferir ferramentas da caixa e do patch
rsync --version
patch --version
# se algum faltar:
sudo apt install -y rsync patch
Terminal · criar nota na cópia, sem chave
cd ~ && ~/caixa-do-agente/caixa.sh ~/intelecto-v2 --imagem python:3.12-slim -- sh -c "echo teste > nota.txt"
Terminal · ler o patch (q sai do less)
less ~/caixa-AAAAMMDD-HHMMSS.patch
Terminal · aplicar o patch lido
cd ~/intelecto-v2 && patch -p1 < ~/caixa-AAAAMMDD-HHMMSS.patch
cat nota.txt
Terminal · desfazer a nota de prova
cd ~/intelecto-v2 && rm nota.txt
Segunda prática · testes na imagem do projeto
cd ~/intelecto-v2
docker build -t intelecto-v2-testes caixa/
cd ~/caixa-do-agente
./caixa.sh ~/intelecto-v2 --imagem intelecto-v2-testes -- python3 -m pytest -q -p no:cacheprovider
Opcional · auditar o projeto
cd ~/caixa-do-agente
python3 auditar.py ~/intelecto-v2
OPCIONAL · exemplo de agente na caixa, não executado neste curso
cd ~/caixa-do-agente
./caixa.sh ~/meu-projeto --rede --env ANTHROPIC_API_KEY -- npx -y @anthropic-ai/claude-code -p "rode os testes" --dangerously-skip-permissions

diff -ruN -x node_modules -x .venv -x __pycache__ -x '*.pyc' -x .npm -x .cache -x .git antes/nota.txt trabalho/nota.txt
--- antes/nota.txt	1969-12-31 21:00:00.000000000 -0300
+++ trabalho/nota.txt	2026-11-13 00:59:26.721454106 -0300
@@ -0,0 +1 @@
+teste

patching file nota.txt

teste

O diff acima é o patch real completo; abaixo dele, “patching file nota.txt” e “teste” são as saídas reais de aplicar e ler a nota. A data de 1969 no cabeçalho de antes/nota.txt é normal para um arquivo novo: antes da execução ele não existia.

67 passed, 1 skipped
0 arquivo(s) mudaram

Estes números são documentados nas fontes, não foram capturados nesta rodada. A quantidade pode mudar no seu projeto.

04 · O que faz o exemplo opcional com agente

Este exemplo do README da caixa-do-agente não foi executado neste curso. Ele usa a sua chave ANTHROPIC_API_KEY e manda a cópia do projeto pela rede ao serviço do agente. Isso pode consumir a sua assinatura ou créditos do serviço.

./caixa.sh ~/meu-projeto copia esse projeto; --rede libera a internet; --env ANTHROPIC_API_KEY põe só essa chave na caixa. Depois de --, npx -y @anthropic-ai/claude-code -p "rode os testes" inicia o agente com esse pedido; --dangerously-skip-permissions remove as perguntas internas na cópia. A caixa gera um patch para você revisar antes de aplicar ao original.

05 · Faça a prova da maquete

Faça na ordem e marque apenas depois de conferir o resultado.

Faça a mudança e volte ao original

12

Na pasta pessoal, rode o comando sem chave da imagem python:3.12-slim usando ~/caixa-do-agente/caixa.sh. Copie o nome do patch impresso. Abra esse arquivo com less, aperte q para sair; entre em ~/intelecto-v2, aplique com patch -p1, confira com cat nota.txt e desfaça com rm nota.txt.

Pronto quando: O patch lido contém +teste; patch imprime “patching file nota.txt”; cat mostra “teste”; depois de rm, a nota de prova não fica no original.

Rode os testes em outra caixa

8

Em ~/intelecto-v2, crie a imagem intelecto-v2-testes com docker build. Depois, em ~/caixa-do-agente, rode caixa.sh com essa imagem e python3 -m pytest -q -p no:cacheprovider. A bateria bash testes/teste.sh do kit é opcional.

Pronto quando: O pytest mostra seu resumo de testes e a caixa informa quantos arquivos mudaram; compare com a medição documentada, sem exigir os mesmos números.

07 · Leve desta aula

Cria, roda, destróiA caixa trabalha numa cópia sem .env e chaves, e começa sem rede. Com --rede, o conteúdo da cópia pode ser enviado; os recursos continuam limitados.
Você decideO patch mostra mudanças. patch -p1 aplica o arquivo lido; --aplicar inicia outra rodada e pergunta antes de copiar.
Nota com contextoA nota depende dos programas de agente instalados no computador, não da inteligência do modelo.
