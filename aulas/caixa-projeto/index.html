Aula 7 · 20 min

A caixa-do-agente no seu projeto

Antes de deixar um agente mexer no seu projeto, use a caixa-do-agente para trabalhar numa cópia. Sem --rede, ela fica sem internet. Um agente de nuvem precisa de --rede e da chave dele; você revisa o patch (arquivo de mudanças) antes de aplicar no original.

Começar a aula

Nesta aula você vai

  1. 1Entender criar, rodar e destruir
  2. 2Revisar patch e aplicar conscientemente
  3. 3Ler a nota do auditor sem confundi-la com nota do modelo

Objetivo: Rodar as checagens do kit ou executar um projeto na caixa e revisar o patch antes de aplicar.

02 · Duas ferramentas no kit

Clique em cada etapa para ver o que fazer.

1. caixa.sh

O fluxo cria → roda → destrói usa uma cópia: .env, chaves .pem e ~/.ssh ficam fora. Sem --aplicar, o original fica intacto; arquivo excluído na caixa não é excluído no original. Há teto de memória, CPU e tempo.

Com --rede e --env ANTHROPIC_API_KEY, a chave escolhida entra na caixa e o agente pode enviar para fora o conteúdo da cópia. --dangerously-skip-permissions tira as perguntas dentro dessa cópia; leia o patch e nunca ponha outros segredos na pasta de trabalho.

2. Patch

Patch é um arquivo de texto com as mudanças. O .patch fica na pasta de onde você rodou a caixa ou em --patch. Leia o arquivo específico antes de aplicar; patch -p1 leva exatamente essas mudanças ao original. Use o caminho completo que a caixa mostrou para o arquivo, sem selecionar outro patch por engano.

3. auditar.py

O auditor lê Claude Code, Codex e DeepSeek Harness instalados no computador, além do projeto. Harness é o programa que roda comandos do modelo; sandbox é o limite ao que ele alcança. Sem nenhum desses programas, a nota sai baixa e isso é normal; ela não mede a inteligência da IA.

4. Caso real

A prática principal usa o ~/intelecto-v2 que você já baixou. A imagem de testes traz pytest, o programa que roda testes Python, porque a caixa começa sem rede. O README do projeto documenta 67 testes passados, 1 pulado e nenhum arquivo alterado na medição dele; confira sua própria saída.

03 · Use o kit numa pasta de projeto

Use ~/intelecto-v2, baixado na aula 1. Baixe o kit caixa-do-agente uma vez. Os comandos de agente de nuvem e patch são exemplos: precisam da sua chave/assinatura ou de um patch criado por uma rodada com mudanças.

Terminal · baixar o kit e testar
cd ~ && git clone https://github.com/inematds/caixa-do-agente && cd caixa-do-agente
bash testes/teste.sh
Terminal · auditar o projeto da aula 1
cd ~/caixa-do-agente
python3 auditar.py ~/intelecto-v2
Terminal · prática principal: testes numa cópia
cd ~/intelecto-v2
docker build -t intelecto-v2-testes caixa/
cd ~/caixa-do-agente
./caixa.sh ~/intelecto-v2 --imagem intelecto-v2-testes -- python3 -m pytest -q -p no:cacheprovider
Exemplo · agente de nuvem na cópia (precisa de chave autorizada)
./caixa.sh ~/intelecto-v2 --rede --env ANTHROPIC_API_KEY -- npx -y @anthropic-ai/claude-code -p "rode os testes" --dangerously-skip-permissions
Exemplo · aplicar exatamente o patch que você leu
less /caminho/absoluto/caixa-AAAAMMDD-HHMMSS.patch
cd ~/intelecto-v2 && patch -p1 < /caminho/absoluto/caixa-AAAAMMDD-HHMMSS.patch
Exemplo do repositório
67 passed, 1 skipped
0 arquivo(s) mudaram

Esse resultado veio do README do INTELECTO e do guia da caixa. Seu terminal pode mostrar contagens diferentes. Uma rodada de testes sem mudanças não cria patch para aplicar.

06 · Leve desta aula

Você decideO patch mostra mudanças. patch -p1 aplica o arquivo lido; --aplicar inicia outra rodada e pergunta antes de copiar.
