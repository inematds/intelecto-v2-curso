Aula 1 · 12 min

Por que um Jarvis seu, e por que seguro

Antes de confiar seus arquivos à IA, veja o que ela pode fazer e quando pede seu OK. Um erro ou um texto malicioso escondido num site pode levar a IA a apagar uma pasta ou enviar uma senha para fora. Testado em Linux (Ubuntu). macOS: no código, não testado ao vivo. Windows: só pelo WSL (Ubuntu dentro do Windows), não testado. A demonstração usa um cérebro simulado, sem internet.

Começar a aula

Nesta aula você vai

  1. 1Ver as oito peças do assistente
  2. 2Distinguir o assistente da caixa do projeto
  3. 3Ler as três decisões da auditoria

Objetivo: Explicar as oito peças do INTELECTO v2 e reconhecer livre, aprovar e bloqueado na demonstração.

01 · As oito peças

Clique numa peça; o ciclo começa com você e termina com um registro.

Clique em cada bloco do diagrama para ver o que ele faz.

A caixa-do-agente é outra camada: protege a cópia de um projeto quando um agente de programação trabalha nele.

02 · O caminho de uma mensagem

Do terminal ou celular até a resposta, em seis etapas do guia do projeto.

1. Canal

A mensagem chega pelo terminal ou Telegram. No Telegram, o bot confere se o id pertence à lista de donos; outro remetente é ignorado e anotado.

2. Memória direta

Um pedido que começa com “lembre que”, “guarde” ou “anote” é salvo diretamente, sem esperar que a IA chame uma ferramenta. Uma pergunta com ? não vira memória.

3. Contexto

O assistente junta os arquivos de identidade, memórias ligadas à pergunta e conversas recentes.

4. Cérebro

A IA local ou da nuvem recebe esse contexto. Ela responde ou pede uma ferramenta, como buscar memória, ler arquivo ou rodar comando.

5. Trava

O comando pedido passa pela trava: ela roda, pede seu OK ou recusa. Se aprovado, roda na área de trabalho ou na caixa, quando ativada; o resultado volta para a IA.

6. Resposta

Você recebe a resposta. Comandos, ferramentas, memórias diretas e erros ficam registrados na auditoria para conferência.

03 · O que a demonstração prova

Clique em cada etapa para ver o que fazer.

1. Prepare o terminal

No Linux (Ubuntu), instale Python 3.10+ e git. No macOS, instale as ferramentas de comando com xcode-select --install; Python 3.10+ vem de python.org ou de brew install python. No Windows, use WSL com Ubuntu. Confira as versões antes de continuar. Se python3 --version mostrar menos que 3.10, use Ubuntu 22.04 ou mais novo antes de continuar.

2. Baixe e rode a demonstração

Baixe o INTELECTO, entre na pasta e rode demo. A demonstração usa um cérebro simulado e mostra memória, leitura permitida, escrita recusada e comando bloqueado.

3. Memória

O cérebro simulado guarda “meu nome é Ana e moro em Curitiba” e responde à pergunta seguinte. Esta prova é do mecanismo; na aula 3 você fará o teste com Ollama.

4. Comandos

“ls” roda. “echo teste > nota.txt” pede aprovação e é recusado na demo. “rm -rf /” fica bloqueado.

5. Área

O pedido para ler ../../etc/passwd recebe “fora da pasta de trabalho”.

04 · Rode sem instalar modelo

No macOS, Python 3.10+ também pode vir de python.org; use brew install python apenas se tiver Homebrew. Rode os blocos do seu sistema e depois baixe o projeto.

Linux (Ubuntu) · pré-requisitos
sudo apt install -y git python3 curl
python3 --version && git --version
macOS · instalar ferramentas do terminal e git
xcode-select --install
git --version
macOS · Python 3.10+ com Homebrew
brew install python
python3 --version
Terminal · baixar o projeto e entrar
cd ~ && git clone https://github.com/inematds/intelecto-v2 && cd intelecto-v2
Terminal · rodar a demonstração
python3 -m intelecto demo
Exemplo do repositório
livre     rodou=True  ls
aprovar   rodou=False echo teste > nota.txt
bloqueado rodou=False rm -rf /

4
