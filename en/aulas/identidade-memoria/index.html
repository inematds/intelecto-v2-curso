Lesson 3 · 15 min

Give the assistant an identity and memory

Change how the assistant speaks and save facts for another conversation. Since v2.0.1, “remember that…” is saved directly, even with llama3.2. Check the fact with the memoria command; a friendly response alone doesn’t prove it was saved.

Start the lesson

In this lesson, you’ll

  1. 1Tell the four files apart
  2. 2Save a lasting fact
  3. 3Find the same fact later

Objective: Edit the identity and find a fact you told the assistant using the memoria command.

01 · Four files, different roles

The identity is in ~/.intelecto2/identidade/.

Click each block in the diagram to see what it does.

Click each part to see what it does.

02 · Identity isn’t automatic recall

Click each step to see what to do.

1. Edit the person

Describe who you are without a password. In the nano editor, save with Ctrl+O, Enter, and exit with Ctrl+X.

2. Edit the style

Change the personality in everyday language. Keep the safety rules in AGENTS.md.

3. Share a fact

After the first run, adding facts to MEMORY.md won’t help: it has already been imported. In the conversation, say “remember that my city is Porto Alegre.” Version 2.0.1 saves the fact directly, without relying on the model to call salvar_memoria; “remember,” “save,” and “note” work too. A message that ends with “?” never becomes a memory.

4. Look it up later

End the conversation, open another one, and ask for the fact. Confirm it with the memoria command using a word from the fact: it checks the database directly, even if the model’s answer varies.

03 · Files and search

In nano, save with Ctrl+O, Enter, then exit with Ctrl+X. MEMORY.md is imported only in a new installation, on the first run; later facts are added through the conversation.

Terminal · open the files
nano ~/.intelecto2/identidade/USER.md
nano ~/.intelecto2/identidade/SOUL.md
Terminal · search for the fact
cd ~/intelecto-v2
python3 -m intelecto memoria Porto
Terminal · list the latest memories
cd ~/intelecto-v2
python3 -m intelecto memoria
Repository example

After “remember that my name is Nei and I live in Porto Alegre,” a new conversation replied: “Your owner’s name is Nei and you live in Porto Alegre.” The search python3 -m intelecto memoria showed #2 … My name is Nei and I live in Porto Alegre. The record number and response may vary in your installation.

04 · Prove the memory works

Follow the steps in order and check each one only after you’ve confirmed the result.

Share a fact about yourself

5

In the conversation with Ollama, including llama3.2, say “remember that my city is Porto Alegre” or share another simple fact. Avoid sensitive information. Then run python3 -m intelecto memoria Porto (replace Porto with a word from your fact).

Done when: The fact appears in python3 -m intelecto memoria [word]; the assistant’s confirmation alone isn’t enough.

Look it up in another run

5

End the conversation, open another one, and ask about the fact. Then return to the terminal and search for a word from the fact with memoria.

Done when: The line you find contains the fact you shared.
