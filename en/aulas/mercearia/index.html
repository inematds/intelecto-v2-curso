Lesson 9 · 18 min

Build your own: the grocery store and meu-assistente.md

INTELECTO v2 is already working. The grocery store helps you choose what to add: it builds an .md file with the ingredients, each one’s status in the project, and rules for a coding agent. You can just read a ready-made example without using an agent or spending credits.

Start the lesson

In this lesson, you’ll

  1. 1Choose ingredients or load a ready-made example
  2. 2Read the total, markers, and files mentioned in the .md
  3. 3Give the agent one item at a time and check the tests

Objective: Choose an example, interpret the .md markers, and say what already exists and what still needs to be implemented.

01 · From choice to work plan

Click the three steps. The symbols show what already exists and what’s missing.

Click each block in the diagram to see what it does.

✅ already exists in INTELECTO v2, with the file · 🟡 exists in part · ➕ needs to be added, with the part to add it to.

02 · What’s in the file

The page builds a work list; it doesn’t install features.

1. Five starting points

Personal Jarvis on Telegram: 12 items (✅ 5, 🟡 3, ➕ 4). Small business assistant: 12 (✅ 2, 🟡 2, ➕ 8). Secure programmer: 12 (✅ 4, 🟡 0, ➕ 8).

2. Two more examples

100% local and private: 10 items (✅ 5, 🟡 1, ➕ 4). Voice-controlled smart home: 12 (✅ 2, 🟡 0, ➕ 10). All five files are in the repository’s exemplos/ folder.

3. Legend

✅ already exists and names the actual file, such as intelecto/canais/telegram.py; 🟡 exists in part and says what’s missing; ➕ doesn’t exist yet and points to the part where the agent can add code.

4. Rules at the end

The .md says to work on one ingredient at a time, write a test in tests/ and run python3 -m pytest -q. It also says to preserve the lock, keep secrets only in the vault, test without a real API, update the process table in README when usage changes, and say “done” only with the test output.

03 · Open an example and hand off the plan

The first try only reads the file and doesn’t use an agent. The second is optional and uses your agent subscription or credits.

Terminal · read the example for free
cd ~/intelecto-v2
less exemplos/01-jarvis-telegram.md
# Press q to exit less.
Terminal · copy the example to the project
cd ~/intelecto-v2 && cp exemplos/01-jarvis-telegram.md meu-assistente.md
With Claude Code or Codex open in the folder
Read meu-assistente.md and implement the items to add and the partial items, one at a time, following the Rules for the agent.
Terminal · count tests before and after an item
sudo apt install -y python3-pytest   # the test program (just once)
cd ~/intelecto-v2
python3 -m pytest -q
Optional practice · request for ONE ➕ item
Read meu-assistente.md. Choose only ONE item marked ➕, implement it, write the test in tests/ and run python3 -m pytest -q. Show the changed code and the test output.

04 · Who does what

The grocery store creates the plan in Markdown. The coding agent writes the code for 🟡 and ➕ items; you need to check its work. This uses your agent subscription or credits. Safer option: run the agent in caixa-do-agente and apply only the reviewed patch to the original.

For a file downloaded from the grocery store, copy ~/Downloads/meu-assistente.md to ~/intelecto-v2/. If you use the repository example, the block above copies it without a download.

After the grocery store: INTELECTO version 2.1 already ships six advanced features, ready and tested (web kept away from memory, verified citations, long-running tasks, routines, backup brain and undo). See all six running with python3 -m intelecto avancado. They are not connected to the conversation yet; ask the agent to connect one at a time, with a test.

05 · Try it in two steps

The first practice doesn’t need an agent, Docker, or payment.

Read the ready-made list

5

Open exemplos/01-jarvis-telegram.md in the repository or download an example from the shop. Find the “Total: …” line and a ✅ item with a file path. In Jarvis, use the Telegram bot as an example.

Done when: You can say: 12 items; ✅ 5, 🟡 3, and ➕ 4; and name the file for one ✅ item, for example intelecto/canais/telegram.py.

Optional: implement just one ➕

12

Install the test program once (sudo apt install -y python3-pytest). Copy meu-assistente.md to ~/intelecto-v2, run python3 -m pytest -q, and note how many tests pass. Give the agent just ONE ➕ item, following the file’s rules. The agent writes the code; check the patch or changes and run the tests again. This uses your subscription or the agent’s credits.

Done when: python3 -m pytest -q passes after the change and shows more passing tests than before. You checked the code the agent produced.
